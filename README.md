## ✨ Features & Highlights

- 🏹 **Authentic Arrow Ballistics**: True-to-life parabolic arrow drop over distance, flight velocity, and crosswind drift.
- 💨 **Dynamic Wind Vane**: Variable wind strength and directional indicators that challenge your aim adjustments.
- 🎯 **Moving Holographic Targets**: Bullseye rings, concentric score tiers, and bonus target balloons.
- 🔊 **Procedural Audio**: Bowstring tension groans, satisfying arrow release whooshes, and crisp thud impacts on target straw.
- 🏆 **Arcade High Scores**: Integrated with the Marcus Arcade Hub leaderboard.
